# Documentación UML — Ecommerce Motos

---

# Descripción

Esta carpeta contiene la documentación UML, Scrum y documentación técnica desarrollada para el proyecto Ecommerce Motos.

El proyecto consiste en una tienda en línea orientada a la venta de equipamiento para motociclistas y accesorios para motocicleta.
