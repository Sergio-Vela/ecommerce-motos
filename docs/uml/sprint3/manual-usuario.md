# Manual de Usuario — Ecommerce Motos

---

# Introducción

Este manual explica de forma sencilla cómo utilizar la tienda en línea de equipamiento para motociclistas y accesorios para moto.

---

# Usuarios del sistema

## Cliente
Puede registrarse, iniciar sesión, ver productos, agregar productos al carrito y realizar compras.

## Administrador
Puede gestionar productos, revisar pedidos y actualizar inventario.

---

# Uso del sistema

## 1. Registro de usuario

El cliente ingresa sus datos personales, correo y contraseña para crear una cuenta en el sistema.

---

## 2. Inicio de sesión

El usuario ingresa su correo y contraseña para acceder a la plataforma.

---

## 3. Visualización del catálogo

El cliente puede ver los productos disponibles, como cascos, guantes, botas, chaquetas, impermeables, maletas y accesorios.

---

## 4. Agregar productos al carrito

El cliente selecciona un producto y lo agrega al carrito de compras.

---

## 5. Realizar compra

El cliente revisa los productos seleccionados, confirma la compra y el sistema registra el pedido.

---

## 6. Seguimiento del pedido

El cliente puede consultar el estado del pedido, por ejemplo:

- Pedido creado
- Pago confirmado
- En preparación
- Enviado
- Entregado

---

# Funciones del administrador

- Agregar productos
- Editar productos
- Actualizar inventario
- Revisar pedidos
- Cambiar estado de pedidos

---

# Conclusión

El sistema permite que los clientes compren productos para motociclistas de forma sencilla, mientras que el administrador puede controlar productos, inventario y pedidos.
