# Manual Técnico — Ecommerce Motos

---

# Descripción general

El sistema consiste en una tienda en línea orientada a la venta de equipamiento para motociclistas y accesorios para motocicletas.

El proyecto fue desarrollado utilizando metodología Scrum y documentación UML.

---

# Tecnologías utilizadas

## Frontend
- Angular
- Angular Material

## Backend
- Node.js
- Express

## Base de Datos
- PostgreSQL
- Sequelize ORM

## Control de versiones
- GitHub

---

# Estructura general del sistema

El sistema se divide en:

- Frontend
- Backend
- Base de datos
- Documentación UML
- QA
- UX/UI
- Scrum

---

# Funcionalidades principales

- Registro de usuarios
- Inicio de sesión
- Visualización de productos
- Carrito de compras
- Gestión de pedidos
- Gestión de inventario
- Panel administrador

# Consideraciones técnicas

- El sistema utiliza arquitectura cliente-servidor.
- Se implementa control de inventario.
- Los pedidos quedan registrados en base de datos.
- El sistema permite escalabilidad futura.
