Proyecto Ecommerce MotoStore

Integrante

Pedro – Product Owner

Descripción del Proyecto

MotoStore es un sistema ecommerce desarrollado bajo metodología Scrum orientado a la venta de accesorios y equipamiento para motociclistas.

El proyecto fue desarrollado en 3 Sprints, donde progresivamente se implementaron funcionalidades desde la base técnica inicial hasta un sistema ecommerce funcional y visualmente mejorado.

Rol Desempeñado

Product Owner

Como Product Owner mis responsabilidades principales fueron:

* Definir el alcance del proyecto.
* Gestionar historias de usuario.
* Organizar el Product Backlog.
* Priorizar funcionalidades mediante MoSCoW.
* Validar funcionalidades desarrolladas.
* Revisar cumplimiento de objetivos por Sprint.
* Realizar aceptación final de historias.
* Coordinar revisión funcional del sistema.
